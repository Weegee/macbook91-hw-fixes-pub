macbook91-hw-fixes 20261021.01-1 - RELEASED (tag v20261021.01, 2026-10-21; installed on the test machine for the hardware gate)

What: first release prepared for the public repository. Changes to the
shipped scripts and the package dependencies, plus documentation and licensing
text; no change to the kernel modules or the udev rule.
- The package stands on its own: it no longer depends on
  macbook91-cs4208-dkms, macbook91-facetimehd-dkms and
  macbook91-wireless-dkms. macbook91-hw-verify checks those packages and their
  DKMS modules only where they are installed (INFO otherwise, no FAIL), no
  longer checks for the camera firmware package, and --deep skips a verify
  tool that is not installed.
- Removed: the two macbook91-hw-migrate steps that deleted earlier
  hand-installed files (an NVMe udev rule and a sleep hook of a previous
  setup), the check for that hook in macbook91-lid-wake and the INFO branch for
  it in macbook91-hw-verify. The sleep check no longer accepts such a
  hand-installed hook in place of the packaged one (INFO before): only
  macbook91-lid-wake passes, otherwise the check FAILs. macbook91-hw-migrate keeps backlight-native (default), keyboard-iso
  and hibernate (the last two only when named). Behaviour change: status and
  rollback no longer know the two removed step names; a leftover state record
  applied/legacy-d3cold-rule or applied/legacy-sleep-hook under
  /var/lib/macbook91-hw-fixes is ignored, rollback with such a name reports
  "unknown step", and the record is harmless (VERIFIED by reading the step
  lists, NOT RUN on hardware). The packaged lid hook also no longer stands
  aside for an earlier hand-installed hook of the same kind; two such hooks
  would both toggle LID0, so an earlier hook has to be removed by hand
  (VERIFIED by reading the removed lines, NOT RUN on hardware).
- README: install instructions for Arch Linux (the driver packages are
  optional and have their own instructions; all files of the release go into
  one empty directory; makepkg needs PKGBUILD,
  macbook91-hw-fixes.install and the source tarball; sha256sum -c
  --ignore-missing SHA256SUMS must print OK for those three; make dist needs a
  git checkout), AI assistance note in the wording shared by the four
  repositories, license table with paths of this repository only, and the note that the first three snapshots (20261013.01 to
  20261015.01) carried a GPL-2.0-only notice. LICENSES/GPL-3.0-or-later.txt
  added (identical to LICENSE), the unused LICENSES/MIT.txt removed.
  docs/FINDINGS.md and the Makefile header are worded for a public reader.
- Details: docs/CHANGELOG.md.
